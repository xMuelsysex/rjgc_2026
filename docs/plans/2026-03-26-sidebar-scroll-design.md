# Sidebar Scroll Design

**日期：** 2026-03-26

## 目标

优化主页面左侧导航栏的滚动体验，让滚动更加丝滑，并将滚动条在展开时的视觉效果调整为极简、现代、低干扰的风格。

## 设计方向

本次采用“极简专业感”方案：

- 默认状态下滚动条尽量低存在感，只保留细窄、半透明的辅助感知。
- 当用户将鼠标移动到导航区或滚动条进入展开态时，滚动条平滑增强可见性与厚度感。
- 使用圆角胶囊型 thumb，配合更轻的轨道与过渡动画，避免传统滚动条的生硬感。

## 方案选择

采用 B 方案：全局可复用滚动条主题，但只通过专用 class 作用于侧边导航。

### 原因

- 保持样式集中，便于后续复用。
- 不需要重写业务逻辑或 ViewModel。
- 通过专用 class 限定作用范围，避免影响其他页面的滚动控件。

## 实现范围

### 修改文件

- `hospital_ward/App.axaml`
- `hospital_ward/Views/MainWindow.axaml`

### 样式策略

- 在左侧导航 `ListBox` 上增加专用 class。
- 在 `App.axaml` 中为该 class 定义导航专属的 `ScrollViewer` / `ScrollBar` / `Thumb` 样式。
- 基于 Avalonia Fluent 主题现有模板结构进行覆写，不替换整个控件模板。

## 视觉与交互规则

### 默认态

- 纵向滚动条保持窄而轻。
- Thumb 使用低透明度深灰色胶囊形态。
- 轨道几乎不可见。

### 悬停态

- 当鼠标进入导航区时，thumb 轻微增强透明度与可见性。
- 当滚动条进入 expanded 状态时，轨道与 thumb 进一步清晰，但仍保持极简风格。
- 去掉上下箭头按钮，减少传统控件感。

### 动效

- thumb 的 `RenderTransform`、`Opacity`、`Background` 使用短时长缓动过渡。
- 利用 Avalonia 原生 `AllowAutoHide`、`ShowDelay`、`HideDelay`、`IsScrollInertiaEnabled` 提升交互连贯性。

## 风险控制

- 不重写 `ListBox` 模板，仅覆写必要的模板内部样式，降低破坏性。
- 保持横向滚动关闭，避免多方向样式干扰。
- 不修改菜单项绑定与选择逻辑，确保功能行为稳定。

## 验证方式

- 执行项目构建，确认 XAML 样式通过编译。
- 手动运行主窗口，检查导航栏滚动条默认态、悬停态、展开态是否符合预期。
