# Sidebar Scrollbar Drag Fix Requirement

## Goal

修复主页面左侧导航滚动条无法正常拖动的问题，同时尽量保留当前已经落地的极简现代化视觉风格。

## Deliverable

- 恢复左侧导航栏滚动条 thumb 的正常拖拽能力。
- 不回退整个滚动条改造方案。
- 保持滚动条整体视觉仍为低干扰、现代化风格。

## Constraints

- 仅修改样式层，不改动 ViewModel 和业务绑定。
- 优先做最小修复，避免重新设计完整滚动体系。
- 不影响已有的菜单选择、高亮和列表滚动行为。

## Acceptance Criteria

- 用户可以直接用鼠标抓住左侧滚动条 thumb 并顺畅拖动。
- 滚动条默认态和展开态仍然保持现代化外观。
- 项目可以成功构建，无新增 XAML 编译错误。

## Non-goals

- 不重新设计全应用滚动条体系。
- 不新增自定义控件或代码后端逻辑。
- 不处理与本问题无关的现有编译警告。

## Inferred Assumptions

- 当前拖拽失败是样式层造成的命中区域过小，而非 Avalonia 控件逻辑失效。
- 修复重点是恢复交互可用性，视觉细节可在后续继续微调。
